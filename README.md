# AQRS IT Consulting

Sitio web estático creado con HTML, Tailwind CSS mediante CDN y JavaScript.

## Abrir localmente

Abra `index.html` en un navegador. No requiere instalación ni compilación.

## Publicar en GitHub Pages

Suba el contenido del proyecto a la rama `main` y active GitHub Pages desde la carpeta raíz del repositorio.

## Pendientes antes de publicar

- Sustituir teléfono, correo y ubicación.
- Agregar enlaces de redes sociales.
- Insertar el video de YouTube para inversionistas.
- Agregar nombres y fotografías de los integrantes.
- Crear la bitácora de siete días en Blogger y enlazarla desde `noticias.html`.
