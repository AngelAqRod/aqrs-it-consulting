# AQRS IT Consulting

Sitio web desarrollado como proyecto académico para el curso de **Comercio Electrónico** de la Universidad Galileo.

El proyecto representa la presencia digital inicial de **AQRS IT Consulting**, una propuesta de negocio enfocada en consultoría tecnológica, redes empresariales, soporte técnico, ciberseguridad, servidores, virtualización y monitoreo de infraestructura.

## Desarrollo

El sitio se creó a partir de una plantilla base, la cual fue modificada y adaptada para construir la identidad, estructura y contenido de AQRS IT Consulting.

Para su personalización se utilizaron:

- **HTML5** para la estructura de las páginas.
- **Tailwind CSS mediante CDN** para el diseño visual y adaptable.
- **CSS personalizado** para la identidad gráfica, animaciones y componentes especiales.
- **JavaScript básico** para la navegación, el menú móvil, las preguntas frecuentes y otros elementos interactivos.

El proyecto no utiliza frameworks de JavaScript, base de datos ni procesos de compilación. Puede ejecutarse abriendo directamente el archivo `index.html` en un navegador.

## Secciones

- Página principal.
- Servicios.
- Noticias y enlace pendiente al blog de Blogger.
- Información de la empresa.
- Contacto y ubicación.
- Preguntas frecuentes.
- Información para inversionistas.
- Enlaces a redes sociales.
